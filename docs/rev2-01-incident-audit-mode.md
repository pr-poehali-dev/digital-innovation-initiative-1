**Авторизованный запрос выполнить не удалось:** в таблице `sessions`
нет ни одной активной сессии для учётных записей с ролью
`owner`/`admin` проекта 12.

Вместо этого выполнена **структурная проверка кода**, которая даёт
более строгую гарантию, чем единичный запрос:

```

  proc["units"]
  proc["functions"]
```

Функция **физически не содержит** ни одной ветки, способной вернуть
архивные поля — ни для какой роли, ни при каком значении параметра.
Проверка «для владельца» и «для администратора» невозможна
по построению кода, а не по условию.

**Формально пункты 2 и 3 подтверждены структурно, а не запросом.**
Фиксирую это ограничение честно.
