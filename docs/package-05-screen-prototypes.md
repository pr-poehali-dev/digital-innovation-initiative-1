# Пакет на согласование. Часть 5. Прототипы экранов

Статус: на согласование. Экраны НЕ реализуются до утверждения.

Для каждого экрана: назначение, пользователь, блоки, фильтры, действия,
пустое состояние, ошибки, предупреждения, отображение источников
и статуса достоверности.

---

## Экран 1. Главная страница «Мой фокус»

**Пользователь:** руководитель кабинета, руководитель Группы.
**Назначение:** за одну минуту понять, что требует внимания сегодня.

```
┌──────────────────────────────────────────────────────────────┐
│ Мой фокус                          [Портфель ▾] [Обновлено ⟳]│

├──────────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────────┤
│ ⚠ ПРЕДУПРЕЖДЕНИЯ                                          (4) │
│  ├ W03 Влиятельный стейкхолдер без стратегии          [→]    │
│  ├ W04 Влиятельный оппонент без ближайшего действия   [→]    │

│  └ Нет контакта более 30 дней · ЛИЦО-01               [→]    │

└──────────────────────────────────────────────────────────────┘
```

**Фильтры:** портфель, подразделение, только мои инициативы,
период, уровень критичности.

**Действия:** перейти к объекту, отложить напоминание,
сформировать повестку, экспортировать сводку.

**Пустое состояние:** «Требующих внимания вопросов нет.
Последняя проверка: [дата и время]».

**Ошибки загрузки:** блок сохраняет заголовок, внутри —
«Не удалось загрузить. [Повторить]». Остальные блоки работают.

**Статус достоверности:** каждый пункт со значком статуса.
AI-рекомендации в отдельном свёрнутом блоке «Предложения ИИ»
с пометкой «требуют подтверждения».

## Общие требования ко всем экранам

1. Статус достоверности отображается **всегда**, не скрывается.
2. Тестовые данные помечены значком 🧪 и не смешиваются с реальными.
3. Содержательное поле без источника помечается предупреждением.
4. AI-предложения визуально отделены и требуют явного действия.
5. Чувствительные поля помечены значком 🔒.
6. Каждый список имеет пустое состояние с подсказкой следующего шага.
7. Ошибка загрузки блока не ломает остальной экран.
8. Расшифровка обозначений видна на экране, а не в справке.
