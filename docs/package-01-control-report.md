### 1.1. Разбор единственной ошибки в редактированном мной файле

```
src/lib/api.ts(495,7): error TS6133: 'PPTX_MIME' is declared but its value is never read.
```

**Подтверждение, что ошибка существовала ранее** — сравнение с базовой версией
до моих правок (коммит `e733e3d`):

```

→ 372:const PPTX_MIME = "application/vnd.openxml...presentationml.presentation";
```

Одно вхождение = только объявление, без использования. Следовательно,
неиспользуемая константа присутствовала до моих изменений; я лишь сместил
её строку с 372 на 495, добавив код выше. Ошибка **подтверждена как
ранее существовавшая** сравнением с базовой версией.

## 4. Проверка маршрутов

**Что проверено:** оба маршрута зарегистрированы, страницы импортируются,
обёрнуты в `ProtectedRoute`, production-сборка включает их в бандл.

**Что НЕ проверено:** работа страниц после авторизации под реальной
учётной записью. Скриншот неавторизованного браузера показал форму входа —
это подтверждает **только** наличие защищённого маршрута, но **не**
работоспособность самой страницы.

**Честный статус: маршруты после авторизации не проверены.**
Требуется проверка с вашей стороны либо предоставление тестовой учётной записи.

### 6.2. AI-гипотезы больше не скрываются

Изменена логика: вместо «отдавать только подтверждённое» —
подтверждённые документами функции и AI-группы отображаются **вместе**,
но явно разделены маркировкой. API передаёт по каждому элементу:
источник, статус, уверенность, основание связи.

### 6.3. Архивные сведения — режим аудита

Добавлен параметр `audit_mode`. Архивные описания из типовой практики
доступны **только** владельцу проекта, **только** по явному запросу
и **всегда** с предупреждением, что это не AS IS.

### 6.4. Устранены конкурирующие статусы

Статусы «официальный» и «подтверждённый» существовали вне общего перечня.
Разделено на две независимые оси (описано в части 2 пакета).
